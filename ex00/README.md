# Hiba Alshaweesh - Personal Portfolio

## About the Project

This project is a personal responsive portfolio website built from scratch using HTML5, CSS3, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Git

## Website Sections

- About Me
- Skills
- Projects
- Hobbies
- Contact
- Footer

## JavaScript Feature

The website includes a theme switcher button that changes the background color when the user clicks it.

## Responsive Design

The website uses Flexbox and CSS Media Queries to adapt the layout to different screen sizes.
